About

Cloud, software & AI

Cloud Engineer with over four years of experience designing, automating, and operating multi-cloud infrastructure on Microsoft Azure and Amazon Web Services (AWS). I specialize in Terraform-based infrastructure as code, CI/CD automation, cloud security, and production reliability, delivering secure, scalable, and highly available systems for production workloads.

On Azure, I have engineered hub-and-spoke network architectures, delivered secure CI/CD pipelines for Azure Kubernetes Service (AKS), enforced Zero Trust access with Microsoft Entra ID, RBAC, and Key Vault, and reduced infrastructure costs by 50–66% through rightsizing and serverless migration. I am Microsoft Certified in Azure Administration (AZ-104), Azure Security (AZ-500), and Azure Fundamentals (AZ-900). On AWS, I provision EC2, S3, VPC, and IAM resources with Terraform and Jenkins, and implement CloudWatch and Lambda-based monitoring that detects application issues and triggers automated remediation.

My experience extends to backend development, API integration, and data-driven applications using Python, JavaScript, React, Node.js, and SQL. I am also developing expertise in applied AI, including retrieval-augmented generation (RAG), vector search, LLM evaluation, and model deployment. I am seeking opportunities to apply my cloud engineering, software development, and AI capabilities to deliver measurable business value.
