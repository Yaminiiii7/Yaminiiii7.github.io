About

What I actually do

I work at the layer where cloud infrastructure meets security. Most of my time is spent turning manual, click-through cloud operations into code — Terraform modules, ARM templates, Packer images — and then putting that code behind a pipeline that validates and security-scans it before anything reaches production.

The security half isn't theoretical. I've built hub-and-spoke network architectures with Azure Firewall and Private Endpoints, enforced least-privilege access through Entra ID, Conditional Access, and PIM, and managed the certificate and secret lifecycle in Key Vault. On the other side of the fence, I run assessments with Nmap, Nessus, and Metasploit and write them up with CVSS-scored, remediation-first reporting.

I also care about the numbers. On one engagement I brought Azure spend down by roughly 50–66% through rightsizing, App Service Plan optimization, and a validated migration to Consumption Plan hosting.
